# Release Notes for Mailer

## 1.0.0 - Unreleased

- Initial release.
- Images can be placed in the message body, linked to their public URL or embedded in each email.
- Users matching conditions (Craft’s condition builder) as a recipient type.
- Scheduled sends. Recipients are worked out again when a scheduled send starts.
- Drafts (autosaved) and reusable templates.
- Simple custom user fields are available as variables.
- Variables can be used inside links, and are URL-encoded.
- Unsubscribe links, one-click unsubscribe headers and an unsubscribe list.
- Sends pause after repeated failures and can be resumed. Failed recipients can be retried.
- The mail server’s error message is recorded for failed emails.
- Recent Emails dashboard widget.
- The rich text editor is only loaded on the compose screen.
